# reference/

What the current fwbbowl.com site says, captured on 2026-10-03.

- `content.md`: every price, special, package, hour and league detail, with sources and a NEEDS VERIFICATION list at the top. **This is the source of truth.**
- `screenshots/` and `raw/`: full-page screenshots (desktop + mobile), 2x close-ups of every image, and page text dumps. Run `npm run capture` to regenerate them.

`screenshots/` and `raw/` are **not committed**. They contain the business's own photos and flyers, the current site says those images can't be republished, and this repo is public. Keep them on your machine for checking prices. Nothing in this folder is used by the website build.
